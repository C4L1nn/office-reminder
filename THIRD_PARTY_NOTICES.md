# Third-Party and Public-Source Material

The MIT License in this repository applies to the original Office Reminder source code unless
a file or directory states otherwise.

Some repository resources are snapshots, normalized records, or metadata obtained from public
official sources for provenance, reproducibility, and offline parser testing. These materials
are not relicensed under MIT merely by being present in this repository.

Notable source families include:

- Gelir İdaresi Başkanlığı (GİB) tax-calendar data and source metadata.
- Sosyal Güvenlik Kurumu (SGK) public notice pages and document fixtures.

Source URLs and acquisition information are preserved in the relevant fixture documentation or
metadata where practical.

Contributors should not add third-party datasets, documents, images, fonts, or other assets unless
their redistribution terms have been checked. Prefer scripts that retrieve external material from
its original source when redistribution rights are unclear.
